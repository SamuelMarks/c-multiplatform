# Data Visualization & Complex Components

For applications that need to represent complex relationships, geographic data, or analytics, the framework offers powerful visualization primitives.

## Core Topics

*   **[Node Graphs](node-graphs.md):** Building visual programming interfaces, flowcharts, and dependency graphs (`ui_node_graph_base.h`).
*   **Charts & Graphs:** Rendering performance-optimized statistical charts (`ui_chart_base.h`).
*   **Maps:** Integrating geographic map views and markers (`ui_map_view_base.h`).
*   **Calendars:** Complex date and scheduling grids (`ui_calendar_base.h`).
*   **[Miller Columns](miller-columns.md):** Navigating deep hierarchical data like file systems (`ui_miller_columns_base.h`).
