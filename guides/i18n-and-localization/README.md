# Internationalization (i18n) & Localization

Reaching a global audience requires deep integration with internationalization systems. The framework provides tools for text direction, formatting, and string management.

## Core Topics

*   **[String Translation](string-translation.md):** Managing translation dictionaries and runtime string resolution (`ui_i18n.h`).
*   **[Bidirectional (BiDi) Text](bidi-text.md):** Supporting Right-to-Left (RTL) languages automatically in layouts and text rendering (`ui_bidi_manager.h`).
*   **Locale-Aware Formatting:** Handling dates, times, currencies, and numbers according to regional standards.
*   **Font Fallbacks:** Configuring the font manager (`ui_font_manager.h`) to handle massive character sets smoothly.
