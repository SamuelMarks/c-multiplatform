# Graphics & Shaders

For visually demanding applications, the framework provides low-level hooks into the rendering pipeline for custom graphical effects.

## Core Topics

*   **[Custom Shaders](custom-shaders.md):** Writing and applying custom fragment/vertex shaders to UI elements (`ui_effects_shaders.h`).
*   **Color Spaces:** Managing different color profiles (sRGB, Display P3) for accurate rendering (`ui_color_space.h`).
*   **Color Quantization:** Techniques for reducing color palettes, useful for image processing and performance optimization (`ui_color_quantization.h`).
*   **Visual Effects:** Applying blurs, dropshadows, and other compositor-level effects (`ui_effect.h`).
