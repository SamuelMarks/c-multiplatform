# Data Presentation & Grids

Handling and displaying large, complex datasets efficiently is a common requirement for enterprise applications. This guide covers the framework's data presentation components and strategies.

## Core Topics

*   **Data Sources:** Binding UI components to abstracted data streams and models (`ui_data_source.h`).
*   **[Data Grids](data-grids.md):** Utilizing high-performance, sortable, and filterable data tables (`ui_datagrid_base.h`).
*   **Pagination:** Managing large datasets through chunked data fetching and UI controls (`ui_pagination_base.h`).
*   **Virtualization:** Techniques for rendering only the visible items in massive lists to maintain 60FPS (`ui_list_base.h`).
