# State Management

Managing application and component state is crucial for building reactive UIs. The framework provides several patterns for tracking data, from isolated component-level state to global application providers.

## Core Topics

*   **[Component State & Invalidation](component-state.md):** Managing local state (`user_data`), targeted repaints (`UI_INVALIDATE_LAYOUT`), and the Context/Provider pattern.
*   **Data Binding:** Connecting form controls and UI properties directly to underlying data models.
*   **Signals & Observables:** Implementing reactive state using the upcoming signal engine.
