# Layout & Styling API

The C-Multiplatform UI Engine implements a subset of W3C CSS specifications (Flexbox, Grid, Box Model) using a custom C89 parser and layout solver. It does not use a web browser engine (like WebKit or Blink).

## 1. Supported CSS Features

The layout solver strictly guarantees window resize safety. Because elements must never bleed off-screen, the engine heavily enforces clamping.

*   **Box Model:** `width`, `height`, `padding`, `margin`, `border`, `box-sizing: border-box` (default and strictly enforced).
*   **Constraints:** `min-width`, `max-width`, `min-height`, `max-height`.
*   **Flexbox:** `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`.
*   **Grid:** `display: grid`, `grid-template-columns` (including `fr` units), `grid-gap`.
*   **Positioning:** `position: absolute`, `position: relative`, `top`, `left`, `right`, `bottom`, `z-index`.
*   **Overflow:** `overflow: hidden`, `overflow: scroll`, `overflow: auto`. Virtual scrollbars are automatically generated by the engine.

## 2. Applying Styles

Styles can be applied to `ui_dom_node` structures in two ways.

### A. Inline Styles
Useful for dynamic, coordinate-based positioning (e.g., a drag-and-drop ghost element).

```c
ui_dom_node_set_style(node, "background-color", "#FF0000");
ui_dom_node_set_style(node, "border-radius", "8px");
```

### B. Global CSSOM & Classes
For design systems and static layouts, parse a stylesheet string into the engine's global CSSOM (CSS Object Model) and assign classes.

```c
const char *css =
    ".my-card {"
    "  display: flex;"
    "  flex-direction: column;"
    "  padding: 16px;"
    "  background-color: var(--md-sys-color-surface);"
    "}";

/* Parse into the global stylesheet */
ui_cssom_parse_string(engine, css);

/* Apply the class to the node */
ui_dom_node_add_class(node, "my-card");
```

## 3. CSS Custom Properties (Tokens)

The engine supports dynamic theming via CSS Custom Properties (`var(--foo)`). You interact with the CSS Environment to change themes globally.

```c
/* Set a global token (e.g., swapping to Dark Mode) */
ui_css_env_set_property(engine, "--md-sys-color-surface", "#121212");
ui_css_env_set_property(engine, "--md-sys-color-on-surface", "#FFFFFF");

/* Set a local override on a specific component tree */
ui_dom_node_set_property(node, "--md-sys-color-surface", "#333333");
```

## 4. Scoped CSS Generation

To prevent style bleed in large applications, the engine can generate opaque, scoped CSS classes at runtime.

```c
char scoped_class[32];
/* Generates a unique class like ".btn-a7f2" */
ui_cssom_generate_scoped_class(engine, "btn", scoped_class, sizeof(scoped_class));

/* Insert a rule using the generated class */
char rule[128];
sprintf(rule, "%s { padding: 8px; }", scoped_class);
ui_cssom_parse_string(engine, rule);

/* Assign the scoped class to the component */
ui_dom_node_add_class(node, scoped_class);
```
