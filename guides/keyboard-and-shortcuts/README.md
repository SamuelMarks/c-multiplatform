# Keyboard & Power User Features

For desktop and web productivity applications, robust keyboard support is non-negotiable. This guide explains how to build keyboard-first experiences.

## Core Topics

*   **Hotkey Registry:** Registering application-wide and scoped keyboard shortcuts (`ui_hotkey_registry.h`).
*   **[Command Palettes](command-palette.md):** Building extensible, searchable command interfaces like those found in modern IDEs (`ui_command_palette_base.h`).
*   **Keyboard Responders:** Granular control over keyboard events and event propagation within component trees (`ui_keyboard_responder.h`).
