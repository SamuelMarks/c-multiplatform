# Media & Hardware

Modern applications often need to interface with hardware peripherals and handle multimedia streams. This section details how to use the framework's media and hardware abstractions.

## Core Topics

*   **[Audio Pipelines](audio-pipelines.md):** Managing audio playback, sinks, and routing (`ui_audio_sink.h`).
*   **Video & AV Sync:** Handling video playback and synchronizing audio/video streams (`ui_media.h`, `ui_av_sync.h`).
*   **[Camera Integration](camera.md):** Accessing webcams and hardware cameras for capture and processing (`ui_camera_base.h`).
