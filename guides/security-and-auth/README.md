# Security & Authentication

Handling user authentication and sensitive data requires specific UI patterns and security considerations.

## Core Topics

*   **Authentication Flows:** Integrating standard login, OAuth, and SSO flows into the UI (`ui_auth.h`).
*   **[Secure Input](secure-input.md):** Utilizing specialized controls for sensitive data entry, like masked passwords and PIN pads (`ui_pin_input_base.h`).
*   **Clipboard Security:** Safely interacting with the system clipboard, respecting user permissions and platform constraints (`ui_clipboard.h`).
