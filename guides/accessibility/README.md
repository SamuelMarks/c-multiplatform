# Accessibility (a11y)

Building inclusive user interfaces is a core tenet of this framework. This section provides guidance on utilizing the framework's accessibility primitives to ensure your applications are usable by everyone.

## Core Topics

*   **[Semantic Structure](semantic-structure.md):** Mapping UI components to proper semantic roles (`ui_aria.h`).
*   **[Focus Management](focus-management.md):** Controlling keyboard navigation, focus traps, and logical tab order (`ui_focus_manager.h`, `ui_focus_trap.h`).
*   **Screen Readers:** Using the live announcer to communicate dynamic state changes to assistive technologies (`ui_live_announcer.h`).
*   **Contrast and Visual Accommodations:** Utilizing design tokens to respect user preferences for high contrast and reduced motion.
