# Navigation & Application Shell

Constructing a cohesive application shell requires consistent navigation patterns that adapt to the user's device and screen size.

## Core Topics

*   **Structural Navigation:** Implementing Bottom Nav Bars for mobile, and Navigation Rails or Sidebars for desktop/tablet (`ui_bottom_nav_base.h`, `ui_nav_rail_base.h`).
*   **Contextual Navigation:** Using Breadcrumbs to indicate hierarchy and allow quick traversal (`ui_breadcrumbs_base.h`).
*   **Menus & App Bars:** Building global application menu bars and contextual actions (`ui_menubar_base.h`, `ui_bottom_app_bar_base.h`).
*   **[Predictive Back](predictive-back.md):** Implementing modern gesture-based back navigation with visual previews (`ui_predictive_back.h`).
