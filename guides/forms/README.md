# Forms & Input Validation

Forms are the backbone of data entry in user interfaces. This framework offers a reactive, scalable form management system based on the builder pattern.

## Core Topics

*   **[Reactive Form Models](reactive-forms.md):** Building forms programmatically using `ui_form_builder.h`, `ui_form_group.h`, and `ui_form_array.h`.
*   **[Custom Validators](custom-validators.md):** Applying built-in validators (required, email, pattern) and writing complex custom validation logic (`ui_form_validators.h`).
*   **State Management:** Tracking touched, dirty, valid, and pending states across form controls (`ui_form_control.h`).
*   **[Input Masking](input-masking.md):** Enforcing specific structural formats (e.g., phone numbers, credit cards) during text entry (`ui_input_mask.h`).
