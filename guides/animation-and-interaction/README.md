# Animation & Interaction

Modern interfaces rely on fluid motion, intuitive gestures, and responsive feedback. This guide details how to leverage the framework's robust interaction engines.

## Core Topics

*   **[View Transitions](view-transitions.md):** Seamlessly animating between different UI states and DOM structures (`ui_css_view_transition.h`).
*   **[Motion & Physics](motion-and-physics.md):** Applying CSS motion paths, keyframes, and spring physics to components (`ui_css_motion.h`).
*   **[Gestures](gestures.md):** Recognizing complex multi-touch gestures like pinch, pan, and rotate (`ui_gesture.h`).
*   **[Drag & Drop](drag-and-drop.md):** Implementing rich drag-and-drop workflows (`ui_drag_drop.h`).
*   **Haptics:** Integrating physical feedback on supported platforms (`ui_haptics.h`).
